# 0.5.0-theme.6 验证记录

2026-11-08，版本号 14，最低 API 19。本轮更新应用图标，日历界面与业务逻辑未改动。

## 修改

- 使用直角开口方框与日期方块组成的黑白图标，统一 Android、Web 和离线原型的图形来源。
- Android 提供各密度的传统 PNG 图标、自适应图标和单色层，替换旧的图层式桌面图标。
- Web 提供浏览器图标、普通安装图标及独立的 maskable 图标；离线原型内嵌浏览器图标。
- 图形源文件与导出方法见[双端说明](platform-parity.md)。
