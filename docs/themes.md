# 主题系统

当前版本 `0.5.0-theme.8`，Android、Web 与离线原型共同维护。

## 设置入口

设置 → 外观与主题。风格、字体分开选择；组件微调可覆盖风格的组成部分。中文不单独选择，随英文自动匹配宋体或黑体。风格、字体与组件选项统一按可用宽度自动换列，卡片宽度不超过 208 dp，最后一行和只有少量选项的分组也不会放大填满整行。

风格预览竖屏为 188∶148，横屏为 240∶148，始终等比显示。横屏宽度达到首页的分栏条件时，缩略图相应展示日期、事项与月历的横向组合；窄横屏沿用上下顺序。组件微调的每个选项都配有局部效果预览，名称位于下方；日期和页面顺序预览遵循当前横竖屏及布局，其余预览显示对应组件形态。字体使用真实字体绘制 Aa，名称位于下方，右上角标示单选状态，不加载截图位图。

设置、外观和组件页的选项实时生效并自动保存，右上角 × 或系统返回关闭当前页，保留修改。长按图标显示文字说明，同时提供中英文无障碍说明；切换配色、语言或主题时保留当前层级与滚动位置，旋转后恢复所在页面。事项和纪念日编辑仍需确认保存。

设置按外观、屏幕、日历内容及语言分组，使用图标、黑白开关、分段按钮及字号滑块。字号范围 90%—130%，两侧 − / ＋ 每次调整 5%；旧“大字”偏好按原有 118% 显示，未操作时不会被改为其他比例。

外观分组提供日夜模式：日间白底黑字，夜间黑底白字。默认日间，不跟随系统深色设置自动切换；选择与风格、字体独立。选择后立即应用，关闭、旋转或重新打开均保留选择。日历、设置、事项、纪念日、编辑控件和主题预览均使用对应配色。

## 日历视图和布局

默认使用月视图和主副排版。周视图在设置中选择，以周一至周日显示七行日期、首条事项与条数；点选日期更新原有事项区。大日期始终显示今天，切换周/月和翻页不会将其搬至其他区域或替换为所选日。

月视图保留原有日期格、事项点、辅助文字及排版。“主副排版”遵循当前风格的区域顺序与比例：普通横屏为日期与事项在左、日历在右；今日看板横屏为日期与事项在上、日历在下。竖屏沿用原有上下顺序。

“对半双栏”为独立的横屏布局选项：日历和日期/纪念日/事项各占一半，左右顺序跟随风格的日历优先或事项优先设置。仅在横屏且宽度达到 640 dp 时生效，竖屏与窄横屏保持原有结构。桌面展示模式仍隐藏日历。

横屏月历根据首屏剩余高度按比例收紧字号和行距，优先完整显示单月六行日期；日历保持原有列宽及左右边距，日期、纪念日和事项区保留原有位置。缩放不放大月历，最低为原尺寸的 55%，以免极低窗口挤成不可用的日历。竖屏、周视图与日期跳转表单保持原有尺寸。

主题缩略图同时跟随当前周/月视图和横屏布局。浏览器原型及其修改入口见 [preview](../preview/README.md)。

切换风格会恢复该风格的组件；英文字体保持独立。风格、组件都可自由搭配所有英文字体。相近的“墨印经典”已合并至“报刊编辑”，后者为默认风格。没有 Inter，也没有全月历方格选项。

事项点采用固定 4 dp 的独立圆点，所有日期预留相同位置；数字、圆点、农历/节气辅助文字分别布局。圆形选中的黑底只作用于数字区域，事项点在圆形下方；周线月历选中格内使用白点；票据月历使用数字下划线。日期选中与有无事项的无障碍描述分别保留。

## 与主线功能的关系

保留自动/强制横屏/强制竖屏设置和新版纪念日导航，以及滑动翻月、日期跳转、独立农历/节气/假期开关、完成状态、7/30 天事项、纪念日与倒计时、两项置顶上限、桌面模式、全屏与常亮。字体沿用到事项表单、日期选择、未来事项和纪念日表单；图标按钮与页面分隔线跟随主题。

桌面模式保持隐藏月历并限制近期未完成事项的原有功能；“今日看板”只是可用于普通月历和桌面模式的视觉预设，不会偷偷打开桌面模式。语言不翻译用户事项内容。

主题保存在原有 `display` SharedPreferences 的 `theme_*` 键。旧版没有这些键时默认报刊编辑；原先的 `original` 风格兼容映射到报刊编辑，字体与显式组件微调保留。未知风格、字体或组件值回退到有效预设，不改动数据库、完成状态、纪念日或其他显示选项。数据库仍为主线版本 2。
