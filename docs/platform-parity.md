# Android、Web 与原型的维护

Android 使用原生界面和 SQLite；Web 使用浏览器界面和 IndexedDB。两端共同维护功能、样式与业务规则，目前没有服务器、账号或跨端数据同步。原型是 Web 共用代码的演示入口。

## 共同来源

- `shared/calendar-contract.json`：主题配方、字体对应关系、日夜配色、显示默认值、字号范围、网格尺寸和事项等约束。
- Android 的 `res/values*/strings.xml`：共同界面文案；Web 的平台专属提示留在 Web 源码。
- Android 的 `assets/calendar/` 和 `Holidays.java`：离线农历、节气、节日及已收录的调休安排。
- `shared/parity-cases.json`：两端均执行的日期、事项、农历、周年计算及日夜模式迁移用例。

在项目根目录运行 `node tools/generate-shared.mjs`，生成 Android 的 `SharedThemeCatalog.java` 和 Web 的 `src/generated/`。不要手改生成文件。`node tools/generate-shared.mjs --check` 检查生成文件是否过期，Web 测试也会执行此检查。

Web 和原型直接共用 `web/src/ui/`、`domain/` 及字体来源。`npm --prefix web run build` 同时生成 Web 构建和原型文件。Android 的渲染代码独立实现；新增共同选项时必须同时修改原生界面及 Web，并补充能够反映实际行为的共同用例。

## 保持一致的行为

- 月视图保留当日日期、纪念日和事项区的位置。周视图只替换日历面板，选择其他日期不会改变主日期。
- 横屏默认使用原有框架；对半双栏是可选布局。窄窗口和竖屏使用纵向排版。
- 横屏月历按首屏可用高度等比适配，正常窗口优先显示完整单月，只缩放日历区域，最小比例为 55%。竖屏和周视图保留原尺寸。
- 风格与字体独立选择；更换风格重置组件覆盖。设置、风格、字体和组件实时应用并自动保存；关闭当前页保留修改，事项和纪念日编辑继续显式保存。
- 默认日间白底黑字，夜间黑底白字；选择后立即生效，两端各自记住选择。旧数据默认日间，配色与风格、字体独立。
- 事项支持全天或 `HH:mm` 时间、完成状态、未来 7 / 30 天列表。编辑已完成事项保留其完成状态。
- 纪念日保留起始日期，倒计时保留唯一目标日；首页最多置顶两项。闰日、农历闰月和小月回退规则由共同用例校验。

## 平台差异

Android、Web 与原型共用 `shared/branding/calendar-mark.png` 中的直角开口方框和日期方块图形。运行 `python tools/generate-icons.py`（需要 Pillow）导出图标：Android 提供各密度 PNG、自适应图标与单色层；Web 提供浏览器、普通安装和安全留白更大的 maskable 图标；原型内嵌浏览器图标。修改标志时从同一来源重新导出。

Web 使用真实的本地日期，跨日及重新回到页面时更新。正式入口默认空数据，演示入口使用固定日期和示例事项。

Android 的方向设置控制设备方向；Web 的“页面方向”控制排版，不旋转设备。自动模式跟随窗口比例，宽度仍需满足横向布局的最小值。全屏和保持唤醒只在浏览器支持时可用；全屏需要用户操作，退出全屏或重开页面后可能需要重新开启。Web 默认关闭全屏。

Web 数据归属于当前浏览器和站点地址；更换浏览器、端口或域名会使用另一份存储。保存以一个 IndexedDB 事务提交，成功后才关闭编辑器。保存失败保留当前输入；另一窗口已保存新版本时拒绝覆盖，并明确提示重新载入会放弃未保存修改。空闲窗口及未修改的设置页可自动载入新版本，保留所在页面。设置自动保存失败时保留当前选择并提供重试，仅重写尚未保存的设置项，保留期间更新的其他选项与事项。

Web 不连接 Android 数据库。所在页面、未保存的表单以及自动保存失败的设置选择存于当前标签页的会话存储；原型使用另一份演示存储。清除站点数据会删除 Web 日历，当前没有导出功能。

构建版包含离线缓存和完整字体；首次完整加载后可在同一地址离线使用。开发服务用于修改预览，不安装离线缓存。发布到服务器时离线功能需要 HTTPS；本地回环地址可直接验证。

## 验证

共同功能改动至少执行：

```sh
node tools/generate-shared.mjs --check
./gradlew testDebugUnitTest lintDebug assembleDebug
npm --prefix web test
npm --prefix web run build
```

Windows 使用 `gradlew.bat`。浏览器验收脚本需要 Python Playwright 和 Chromium；先启动开发服务，再运行：

```sh
python web/tests/browser_check.py
```

构建版可用另一个本地端口运行 `npm run preview`，并将地址传给 `--production-url`，验证离线缓存。脚本使用隔离的浏览器环境，不读取日常浏览器的数据；可用 `--screenshots` 将截图保存到本地忽略目录。

检查事项和纪念日操作、自动设置应用与保存重试、表单保存失败、刷新与窗口变化、表单取消、多窗口冲突，以及五种风格在周/月视图、主副/对半布局中的表现。Android 的面板残影、触控、旋转和功耗仍需真实设备验证。
