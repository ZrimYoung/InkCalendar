# 0.5.0-theme.7 验证记录

2026-11-08，版本号 15，最低 API 19。

## 修改

- Android、Web 和离线原型增加“设置 → 外观 → 日夜模式”：默认日间白底黑字，可选择夜间黑底白字。
- 设置页保存后应用并记住选择；取消保留已保存配色，未保存选择可随旋转或页面重开恢复。旧设置缺少此项时默认日间。
- 配色覆盖日历、设置、事项、纪念日、编辑输入、主题与组件预览，以及图标、开关、滑块和日期选中态。
- 日夜模式与主题风格、字体独立，保留现有日历框架和横竖屏布局。
