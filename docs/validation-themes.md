## 主题验证

- 六个风格都有精简黑白缩略图；七组英文只展示字体样例。中文按英文自动搭配，未提供独立中文字体选择。
- 风格与字体独立保存；组件微调保存、父页取消、子页取消、关闭重开和 Activity 重建恢复均有覆盖。
- 外观设置中切换字体不会改动事项、完成状态、纪念日或 7/30 天范围偏好。未来事项与纪念日入口在各预设保留。
- 所有预设在大字模式检查数字、4 dp 圆点、农历辅助文字的独立位置。圆点不再使用日期文字中的符号。
- 中英混排保持原内容，中文 span 不覆盖拉丁片段；对应中英文家族缓存复用。Android 4.4 的标题字距 span 保留文字和按词换行。
- 渲染六种预设、设置页和外观页，另检查极简、票据、今日看板的 320 dp 大字与 720 dp 横屏中英文布局。实际可见文字宽度在组件边界内。
- 修正过窄屏大日期布局缓存引起的裁切，改用独立测量画笔；事项的时间/标题按可用宽度分配。缩略图的日期、月历和事项区域不叠放。

主线的农历/节气独立开关、节假日、完成/撤销、编辑保留完成状态、未来事项、纪念日增改删、桌面模式、数据库 1→2 升级等原有测试继续通过。数据存储、农历算法、纪念日算法、节假日表和 Manifest 未修改。
