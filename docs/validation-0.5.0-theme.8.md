# 0.5.0-theme.8 验证记录

2026-11-09，版本号 16，最低 API 19。

## 修改

- 日夜模式、字号、方向、布局、开关、语言、风格、字体和组件选项实时生效并自动保存。
- 设置及主题子页使用 × 关闭，关闭或系统返回保留修改；事项和纪念日编辑继续确认保存。
- 切换配色、语言或主题时保留设置层级与滚动位置，滑块拖动时保持控件稳定。
- 默认日间白底黑字，可切换夜间黑底白字；Android 禁用系统对应用界面的额外强制反色。
- Web 自动保存失败保留选择并提供重试，重试仅更新尚未保存的设置项，保留期间更改的其他偏好和事项。空闲设置页可跟随同一站点其他窗口的修改。
