# 墨水屏设备验收清单

状态：目标设备未连接，以下均待执行，不代表通过。

## 设备信息

记录品牌型号、Android 版本 / API、内存、分辨率、屏幕尺寸、触控能力、前光设置、系统刷新模式。若设备低于 API 19，当前安装包不适用，需要重新评估。

## 安装与布局

- 首次离线安装、冷启动、返回主屏后再次打开均正常。
- 竖屏和横屏下大日期、月历、按钮无文字重叠；小屏可滚动到事项区域。
- 开启大字、切换全屏后仍可操作设置和日期；从系统边缘可唤出导航。
- 黑白显示模式下今天、选中日期、邻月日期及事项标记可区分，文字清楚。
- 键盘弹起时可编辑事项并完成保存；屏幕旋转后未保存的内容仍在。

## 事项

- 添加全天事项、09:30 事项，重启应用后仍存在，显示顺序正确。
- 编辑标题、日期、时间；修改后新日期显示标记，旧日期在无其他事项时去掉标记。
- 输入空标题、非法时间时无法保存，已填内容保留。
- 删除取消不改变记录；确认删除后重启仍不出现。
- 今天视图只展示今天至第六天；选中其他日期只展示该天。
- 将系统时区从上海改为其他地区，既有事项仍在原日历日期。

## 衬线体与语言（0.2.0）

- 简体中文 / English 切换后，月名、星期、设置、编辑和删除窗口、错误提示均对应新语言；关闭再打开应用后语言选择保留。
- 切换语言后已有中文或英文事项文字不变，日期和时间也不发生迁移。
- 大日期、中文正文、英文正文及对话框均使用内置衬线字体；确认旧设备正常加载 OpenType 字体。
- 五类线条图标可点击，长按有对应语言说明；无障碍读屏能读出图标用途。
- 开启大字并切换英文，检查较长月份名称和窄屏布局没有遮挡。

## 跨日与显示

- 前台保持打开跨过午夜：日期、今天标记和七天事项更新。
- 月末和年末跨日正常；查看历史日期时跨日不打断历史选择。
- 后台或设备休眠后再打开，日期立即校正。
- 保持唤醒开关只影响应用前台，不永久改变系统息屏时间。
- 长时间静止时没有应用主动的秒级/分钟级刷新；日期或事项更改能够刷新。
- 连续翻月、添加和编辑后观察残影，记录设备刷新模式与必要的厂商适配。
- 插电与电池两种状态各验证连续摆放；记录至少 24 小时耗电及设备是否强制休眠。未测量前不宣称低耗电或全天可靠。

## 版本覆盖

最低目标 Android 4.4（API 19）验证安装、原生控件和 API 兼容；现代 Android 15（API 35）验证全屏边界与导航可达。模拟器结果不能替代目标墨水屏的刷新和耗电实测。
