# 墨水屏设备验收清单

当前版本验证见 [0.5.0-theme.8 验证记录](validation-0.5.0-theme.8.md)，双端差异见[双端说明](platform-parity.md)。此前的图标验证见 [0.5.0-theme.6 验证记录](validation-0.5.0-theme.6.md)，功能验证见 [0.5.0-theme.5 验证记录](validation-0.5.0-theme.5.md)。历史结果保留在 [0.5.0-theme.2 验收记录](validation-0.5.0-theme.2.md)和 [0.4.1 验收记录](validation-0.4.1.md)。以下保留完整验收范围，未在验证记录中列为通过的项目仍待执行。

## 设备信息

记录品牌型号、Android 版本 / API、内存、分辨率、屏幕尺寸、触控能力、前光设置、系统刷新模式。若设备低于 API 19，当前安装包不适用，需要重新评估。

## 安装与布局

- 首次离线安装、冷启动、返回主屏后再次打开均正常。
- 竖屏和横屏下大日期、月历、按钮无文字重叠；小屏可滚动到事项区域。
- 自动、强制横屏、强制竖屏选择后立即生效并在重开后保留；自动遵循系统旋转锁定。
- 横屏主副排版和对半双栏均检查完整单月的首屏显示；需要时仅缩放月历，保持原列宽、外边距和左侧日期、事项布局。
- 月视图与周视图切换只改变日历区域，保留当日日期及事项位置；检查月末、跨月周和六行月份。
- 开启大字、切换全屏后仍可操作设置和日期；从系统边缘可唤出导航。
- 黑白显示模式下今天、选中日期、邻月日期及事项标记可区分，文字清楚。
- 新安装与旧版本升级默认日间；切换夜间后立即，日历、设置、事项、纪念日及编辑页均为黑底白字，图标、开关、滑块、光标和选中日期清楚可见。关闭和重开后保留选择。
- 键盘弹起时可编辑事项并完成保存；屏幕旋转后未保存的内容仍在。

## 事项

- 添加全天事项、09:30 事项，重启应用后仍存在，显示顺序正确。
- 编辑标题、日期、时间；修改后新日期显示标记，旧日期在无其他事项时去掉标记。
- 输入空标题、非法时间时无法保存，已填内容保留。
- 删除取消不改变记录；确认删除后重启仍不出现。
- 今天视图只展示今天至第六天；选中其他日期只展示该天。
- 将系统时区从上海改为其他地区，既有事项仍在原日历日期。

## 字体与语言（0.5.0）

- 简体中文 / English 切换后，月名、星期、设置、编辑和删除窗口、错误提示均对应新语言；关闭再打开应用后语言选择保留。
- 切换语言后已有中文或英文事项文字不变，日期和时间也不发生迁移。
- 七组英文字体分别检查大日期、正文及对话框；中文自动搭配内置宋体或黑体，确认旧设备正常加载字体且混排字形完整。
- 五套风格与字体独立保存；组件微调与恢复预设实时生效，关闭与旋转后保留选择，切换不改动事项和纪念日。
- 字号可在 90%—130% 间调节；滑块呈黑白样式，左右减号、加号每次调整 5%，预览与首页字号一致，调节后自动保存。
- 五类线条图标可点击，长按有对应语言说明；无障碍读屏能读出图标用途。
- 开启大字并切换英文，检查较长月份名称和窄屏布局没有遮挡。

## 跨日与显示

- 前台保持打开跨过午夜：日期、今天标记和七天事项更新。
- 月末和年末跨日正常；查看历史日期时跨日不打断历史选择。
- 后台或设备休眠后再打开，日期立即校正。
- 保持唤醒开关只影响应用前台，不永久改变系统息屏时间。
- 长时间静止时没有应用主动的秒级/分钟级刷新；日期或事项更改能够刷新。
- 连续翻月、添加和编辑后观察残影，记录设备刷新模式与必要的厂商适配。
- 插电与电池两种状态各验证连续摆放；记录至少 24 小时耗电及设备是否强制休眠。未测量前不宣称低耗电或全天可靠。

## 农历、事项与纪念日（0.4.x）

- 农历、节气与节假日三个开关独立生效，切换语言和重开后保留；未知年份明确提示调休数据未收录。
- 核对春节、补班、节气样例及中英文显示；确认月历小字实际可见。
- 完成、撤销、编辑保留完成状态与隐藏已完成正常；未来 7/30 天范围包含首日且边界正确。
- 纪念日、农历纪念日与倒计时增改删、周年天数、到期后显示、两项置顶上限和重开持久化正常。
- 纪念日页右上角关闭、列表下方新建可用；旋转后未保存草稿仍在编辑页。
- 桌面展示模式隐藏月历，只显示最多两项置顶和三条近期未完成事项，关闭后恢复月历。

## 版本覆盖

最低目标 Android 4.4（API 19）验证安装、原生控件和 API 兼容；现代 Android 15（API 35）验证全屏边界与导航可达。模拟器结果不能替代目标墨水屏的刷新和耗电实测。
