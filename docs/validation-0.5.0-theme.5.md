## 修改

- 设置按图标分组，使用黑白开关、分段按钮及字号滑块。− / ＋ 每次调整 5%，范围为 90%—130%；保留旧大字偏好的 118% 比例。

- 主题缩略图跟随周/月视图、横屏布局和方向草稿。
- 项目内浏览器原型可离线打开，样式与逻辑分文件维护，使用应用相同的字体、风格配方与历法数据。原型保存独立示例数据，不访问设备数据库。
