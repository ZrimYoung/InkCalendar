- 农历逐日连续性覆盖 1900—2100 年；每年 24 节气，共 4824 条。独立日期样例参考香港天文台，2026 放假补班表参考国务院通知；来源与推算边界见 `calendar-data.md`。

## 界面检查发现及修正

- 农历辅助文字使用 `setSingleLine` 时在当前字体/布局下发生裁切，改为最大一行布局并为大字/系统字号预留高度；新增像素检查防回归。
- 新增设置复选框为另一种语言预留换行高度，减少语言切换跳动。
- 纪念日和事项草稿重建恢复时先恢复列表、后恢复编辑页，避免列表盖住编辑内容。
- 英文天数使用单复数资源；农历生日闰月和月末规则在表单中明示。

## 另一设备建议验收路径

1. 用 APK 覆盖安装 0.3.4（如已有），确认原事项仍在；不要卸载或清除数据。
2. 切换中文，分别开启/关闭农历、节气、节假日，确认互不联动；切换英文再回来确认选择保留。
3. 点击年月跳到 2026-02-17（春节/休）、2026-02-14（补班）、2026-11-07（立冬）；滑动月份，确认选中日期和详情对应。
4. 添加普通事项，完成、撤销、编辑；打开未来事项切换 7/30 天及隐藏已完成。
5. 添加纪念日和倒计时，查看到期前后、周年和已过天数；置顶两项后尝试第三项，确认提示；修改/删除并重启确认持久化。
6. 打开桌面展示模式，确认今日、置顶项和最多三条近期未完成事项；关闭恢复月历。
7. 在大字号、横竖屏、全屏/系统栏状态下试用新增页面和软键盘；核对字形、触控与刷新。

年度放假/补班数据目前只收录 2026 年，其他年份会明确提示未收录。农历和节气并非按每个设备时区重新推算的天文瞬间。完整规则见 `calendar-data.md`。
