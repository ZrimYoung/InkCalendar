# 0.3.1 验证记录

2026-11-05。

## 修改

- 根据用户反馈移除暖纸色和暗红标记，界面颜色统一为 #FFFFFF / #000000；非当前月日期改用较小字号区分。
- 设置页使用自定义标题、分隔线和方形按钮，不再采用 Holo AlertDialog 布局；复选/单选标记自行绘制，继续保留原生控件的无障碍语义。
- 月历区域支持左右滑动翻月。垂直手势交还 ScrollView，短滑动、明显斜滑、多指操作不触发翻月；拖动时取消日期点击，无动画。

## 自动检查

- 离线构建成功；17 项单元测试通过，0 失败 / 0 错误（新增 5 项滑动方向/阈值检查）。
- Lint 0 错误、5 项警告：原有 4 项，新增 ViewConstructor 提醒。MonthSwipeLayout 只在代码中创建并注入翻月监听器，不从 XML 加载。
- 浏览器回归：42 个日期、5 个图标、双语切换、保留事项原文、键盘选择与焦点恢复、输入校验、添加事项、大字模式和窄屏布局均通过，无脚本错误。
- 浏览器实际拖动检查：左滑下个月、右滑上个月、竖向拖动不翻月；主界面背景计算值为 rgb(255, 255, 255)。
- APK 的 v1 / v2 签名验证通过，最低 API 19。
