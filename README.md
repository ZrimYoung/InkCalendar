# 墨日历 · InkCalendar

面向低配置安卓墨水屏的离线桌面日历。名称为暂定方案，当前主屏采用简洁的报纸式衬线排版。

## 第一版功能

当前版本：0.4.0（待真机验收测试版）。纯白底黑字、衬线标题、粗细分隔线与方形线条图标；横屏以细线分栏，竖屏上下排列。添加、编辑、日期选择、删除确认和设置均采用统一页面样式。可切换简体中文 / English，统一文字行高并预留两种语言的换行空间。

内置 Noto Serif SC 中文字体、Source Serif 4 派生的英文标题字体和 EB Garamond 派生的英文正文字体，均为静态字体、离线显示。字体来源、生成方式与许可证见 `docs/fonts.md`。图标保留 48 dp 点击区域和双语无障碍说明，长按可查看含义。

- 大日期、星期、周一开始的月历；点击日期查看当日事项。
- 右上角日历图标用于回到今天；已经选中今天时，点击会提示“已在今天”。长按图标可查看含义。
- 月历区域左滑进入下个月、右滑回到上个月；保留翻月按钮。上下滑动用于滚动，短距离或明显斜向拖动不翻月，无翻页动画。
- 选中今天时显示包含今天在内的未来七天事项，全天事项排在当日定时事项前面。
- 本地添加、编辑、删除事项；可选 24 小时制时间，留空表示全天。点击事项编辑，删除需要确认。
- 事项表单使用黑色边框、衬线输入文字和黑色光标，校验错误直接显示在页面内。日期选择支持自绘月历、左右滑动和直接输入 YYYY-MM-DD；取消日期选择保留原草稿。
- 切换界面语言只改变界面、日期和提示文字，不翻译或修改用户填写的事项。
- 横竖屏布局；默认全屏，可在设置关闭，主界面和事项页面均跟随该开关。保持唤醒、大字模式也可在设置中调整。
- 前台跨午夜换日；恢复前台或系统时间、时区变更时校正日期。浏览其他日期时保留所选日期。
- 纯黑白、高对比、无页面切换动画、无秒针、无网络权限、无第三方运行时依赖。界面不使用暖色背景、红色标记或系统蓝色设置控件。

## 0.4.0 新增

- 农历和二十四节气仅在中文界面显示，分别可关闭；1900—2100 年数据内置离线使用。
- 中国节日名称支持中英文；节假日与调休有独立开关。已收录 **2026 年**官方放假/补班日期，其他年份只显示节日名称，不推算调休。月历使用黑白「休 / 班」「Off / Work」，选中日期下方显示详情。
- 事项可勾选完成、取消完成；已完成内容使用删除线，可在设置或未来事项页隐藏。编辑事项保留完成状态。
- 事项区的列表图标打开未来事项，切换包含今天的 7 天 / 30 天；可继续编辑和勾选事项。
- 点击月历的年月标题打开日期页，直接输入日期或选择月历，快速跳转。
- 纪念日与倒计时独立管理，可添加、编辑、删除、置顶；首页最多显示两项。纪念日显示下一次周年及已过天数，倒计时显示距目标日或目标日已过天数。
- 中文可选择按农历纪念；公历 2 月 29 日在平年按 2 月 28 日，农历闰月在没有该闰月的年份按同名常月，三十遇小月按廿九。起始日期保持不变；起始日/目标日当天计为 0 天，不做包含首尾日的加一计算。
- 设置中的桌面展示模式隐藏月历，突出今日日期、最多两项置顶纪念日和未来七天最多三条未完成事项；随时在设置关闭返回月历。
- 数据库由版本 1 升级到 2，只增加完成状态字段和纪念日表，保留旧事项。覆盖安装需要继续使用相同签名。

这批功能按用户确认范围开发。ICS 导入、备份恢复、普通事项重复、搜索、长按新建、复制改期和系统桌面小组件均未加入。

## 当前边界

- 兼容目标 Android 4.4 / API 19 及以上，**目标设备尚未实测**。默认假设设备支持触控。
- 保持唤醒仅作用于本应用前台；不强制调整设备前光。它不等于设备休眠后仍能自动更新屏幕。
- 未接入厂商墨水屏刷新 SDK，不承诺局部刷新或消除残影。应用减少重绘触发，实际刷新由设备控制。
- 日期选择范围 1900—2100 年；日期和事项使用本地日历日，切换时区不会平移已有事项。
- 不含普通事项重复、通知响铃、账号同步、系统桌面小组件和开机自启。桌面展示模式是应用内页面，不是系统桌面小组件。
- 事项保存在应用私有 SQLite 数据库。此版无导出功能、系统备份关闭；卸载或清除应用数据会删除事项。后续升级应使用相同应用 ID 和签名覆盖安装。
- 测试包使用调试签名，只用于试用。正式发布前需要另行管理发布签名。

## 构建

使用 JDK 17、Gradle 8.9、Android Gradle Plugin 8.7.3、Android SDK Platform 35 / Build Tools 34.0.0。最低运行版本与构建 SDK 版本不同。

1. 安装 JDK 17 和 Android SDK，在本机 `local.properties` 设置 `sdk.dir`，或配置 `ANDROID_HOME`。
2. 执行 `./gradlew testDebugUnitTest lintDebug assembleDebug`。
3. 测试包位于 `app/build/outputs/apk/debug/app-debug.apk`。

项目不需要 Google Play 服务或运行时联网。开发依赖首次构建时需要联网下载。电脑端测试使用 Robolectric 4.11.1（测试依赖，不打入 APK），首次测试会下载对应 Android 测试运行库。

可执行 `./build-local.sh` 完成测试、静态检查和打包；`./build-local.sh assembleDebug` 仅打包。

## 验收

自动测试覆盖闰年、无效日期、月历首列、跨月跨年、日期范围边界、时区稳定性、夏令时换日，以及事项输入校验。安卓静态检查用于发现低版本 API 使用问题。

已在 Android 11 备用手机检查主界面、设置页、滑动翻月、语言切换后的元素位置及事项增改删流程；该设备不是墨水屏。目标设备到位后，按 `docs/device-checklist.md` 验证低版本兼容、事项持久化、跨日更新、残影与耗电。0.3.4 的真机记录见 `docs/validation-0.3.4.md`。**0.4.0 按用户要求仅进行无设备初步验证，尚未在真机或墨水屏验收**，结果见 `docs/validation-0.4.0.md`。`preview/` 中的浏览器预览仍为 0.3.4 布局，不代表 0.4.0；`delivery/host-*-0.4.0.png` 为电脑端原生渲染检查图，也不是真机截图。
